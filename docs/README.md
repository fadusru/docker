# О проекте

Инструмент Docker расширяет границы для тестирования и эксплуатации приложений.
Для обучения работе с Docker в сети написано много курсов и опубликовано множество статей.

В данной ВиКи совершаю попытку систематизировать свои знания по установке и настройке Docker в разных
операционных системах. Время от времени возникает потребность настроить очередной сервер или рабочее место.
Приходится вспоминать шаги и ключевые фразы чтобы пошагово настроить окружение.
